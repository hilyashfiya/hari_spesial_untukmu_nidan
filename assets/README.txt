=====================================================
PETUNJUK PENGGANTIAN FOTO & VIDEO (PLAYER TWO, FOREVER)
=====================================================

Website ini sudah dirancang dengan fallback otomatis, jadi tampilan
tetap cantik dan tidak rusak meskipun foto/video asli belum dimasukkan.

Saat kamu sudah siap memasukkan foto dan video asli, cukup letakkan file
berikut di folder ini (atau di folder utama website):

1. FOTO KENANGAN:
   - memory-01.jpg -> Foto Momen Pertama / Awal Kenal (Room 2)
   - memory-02.jpg -> Foto Momen Lucu / Kencan Favorit (Room 2)
   - memory-03.jpg -> Foto Kebiasaan / Hal Kecil Bermakna (Room 2)
   - memory-04.jpg -> Foto Perjalanan / Berjuang Bersama (Room 4)
   - memory-05.jpg -> Foto Kebersamaan Terbaik / Favorit (Room 4)
   - memory-final.jpg -> Foto Penutup Spesial (Ending Screen)
   
   * Format yang didukung: .jpg, .jpeg, .png, .webp

2. VIDEO UCAPAN ULANG TAHUN:
   - birthday-message.mp4 -> Video ucapan ulang tahun langsung untuk dia.
   * Format yang didukung: .mp4, .webm

3. KUSTOMISASI TEKS & CERITA:
   - Semua teks cerita, kenangan, dan surat penutup dapat diedit langsung
     pada file index.html pada bagian yang bertanda [PLACEHOLDER: ...].

Selamat merayakan hari ulang tahun pacar tersayang! 💜✨
